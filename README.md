Flappy bird!!

This is a flappy bird arcade game which is a web game project made for Stardance!

Quick start:
download or clone this project repo into a folder on your computer
Ensure you have the three main files inside the same directory
Double click the html file to open it right up in your web browser

Features:
Smooth physics engine with real time gravity and flap veloctiy
Procedural obstacles with infinite randomized pipe gaps
Web audio sound effects with custom sound effects for jumping etc.
Scores and high scores using local storage integration to save personal best

How to run it locally:
System requirements: Any modern web browser
Setup commands: None!

How it works:
This game relies on the browsers requestAnimationFrame to update the canvas at 60FPS instead of using a bloated game engine or downloading other sound files.

Languages: HTML, CSS, Javacsript
